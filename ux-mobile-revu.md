1. Écrans communs — Authentification & onboarding
#	Écran	Fonctionnalités
A01	Splash	Splash animé
A02	Welcome	Présentation + entrée dans l'application
A03	Choix du rôle	Étudiant / Parent / Professeur / Institution / Admin
A04	Connexion	Email/mot de passe, Google OAuth, 2FA
A05	Inscription	Création de compte
A06	Vérification	Code à 6 chiffres, reconfirmation d'identité
A07	Mot de passe	Oubli / réinitialisation / changement
A08	Compléter le profil	Niveau, filière, objectif d'examen
A09	Succès	Confirmation post-inscription
A10	Sessions actives	Appareils connectés + révocation
A11	Confidentialité / suppression	Export des données + suppression de compte

Les fonctionnalités d'authentification et les cinq rôles sont explicitement définis dans le document.
